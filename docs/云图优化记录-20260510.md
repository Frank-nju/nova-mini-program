# 云图（星空知识图谱）优化记录

> 日期：2026-05-10  
> 分支：`develop`

---

## 一、粒子动效条件化（状态 7-8）

**问题**：状态 7 和状态 8 的放射束粒子动效无条件显示。

**改动**：新增 `_allRadialLit()` 方法，检查两个条件：
1. 中心节点 `node_0`（吴健雄）已点亮
2. 所有 8 条 `radial` 连线均已点亮

不满足条件时，状态 7-8 回退显示普通连线图。满足后粒子动效自动出现。

---

## 二、中心节点（node_0）视觉优化

- CSS `is-center is-lit` 核心颜色从蓝色（`#44aaff`）改为微金柔光（`rgba(255, 180, 50, ...)`）
- box-shadow 模糊半径加大（60/120/180rpx），边缘更加柔和空灵
- 呼吸动画 `centerBreathe` 同步改为金色调
- 核心尺寸：32rpx → 35rpx（约 +9%），文字 top 同步调整
- `node_0` 文字保持白色不变

---

## 三、径向线与中心节点的过渡平滑

**问题**：8 条金色径向线与中心节点之间存在视觉脱节。

**方案演进**：
1. 每条径向线中心端添加模糊过渡桥（8 条独立线段）→ 效果不规则
2. 改为单一大面积圆形金色柔光区 `_drawCenterRingGlow()`：
   - 从圆心向外 72rpx 径向渐变，金色从浓到透明
   - 呼吸脉动动画
   - 22 个微粒子在圆形区域内缓慢旋转闪烁
   - 外层 shadowBlur 柔光

**径向线 clip 调整**：中心端 15rpx，外端 9rpx，两端各延长 2-3rpx。

---

## 四、外圈节点放大

CSS 普通节点核心尺寸增大约 12-17%：
- 暗态：12rpx → 14rpx
- 亮态：16rpx → 18rpx
- Canvas clip 半径同步调整

---

## 五、径向线三层渲染（空灵立体感）

每条金色径向线改为双层渲染：
1. 外层空灵光晕：shadowBlur 22，宽线幅，半透明暖金
2. 内层高光亮脊：shadowBlur 5，极细白金色线条，模拟 3D 高光

---

## 六、性能优化

- **setData 拆分**：缩放时只传 `mapScale`（一个数字），不再传整个 `nodes` 数组
- **setData 频率**：非缩放时节点浮动更新从 3 帧 → 4 帧
- **粒子合批**：中心环粒子从 30 次 save/restore 合并为 1 次
- **粒子数量精简约 25-30%**（肉眼不可感知）

| 粒子类型 | 优化前 | 优化后 |
|---------|--------|--------|
| 背景粒子 | 40 | 28 |
| 流束粒子（8线×） | 480 | 336 |
| 火星粒子 | 50 | 35 |
| 轨道环粒子（4环×） | 140 | 104 |
| 中心环粒子 | 30 | 22 |

---

## 七、状态切换平滑化

**问题**：缩放时状态（0-8）瞬间跳变，连线/粒子/文字生硬切换。

**方案**：
1. **浮点状态 + smoothstep**：`drawFrame()` 中用连续浮点值 `sf`（0~8）替代整数 `zoomState`，每个视觉元素的 alpha 通过 smoothstep 在过渡带内渐变：

   | 元素 | 过渡区间 |
   |------|---------|
   | 连线 | 6.5 → 7.5 淡出 |
   | 中心环 | 6.8 → 7.5 淡出 |
   | 节点年份 | 5.2 → 6.0 淡出 |
   | 时钟粒子 | 6.5 → 7.5 淡入 |
   | 中心文字 | 7.5 → 8.0 淡入 |

2. **CSS zoomState 防抖**：整数 `zoomState` 仅在插值结束或每 15 帧更新一次，给 CSS transition 时间播放完。

3. **固定时长 ease-out 动画**：缩放插值从 lerp 改为 15 帧 cubic ease-out，70% 立即响应 + 30% 缓慢到位，状态浮点值在 250ms 内缓慢穿越过渡带。

---

## 八、布局与缩放参数

- **节点扩散**：`buildFromCloud` 中所有节点以中心为原点向外扩散 1.2 倍，节点间距拉大
- **缩放步长**：1.2 → 1.18，9 个层级间距更均匀
