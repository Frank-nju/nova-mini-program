# 前后端接口文档

**版本:** v0.1.1 (W1 Mock版)
**更新日期:** 2026-04-27

> **说明:** W1阶段所有接口返回 Mock 数据，仅供前端联调。W2 将接入真实数据库。

---

## 一、7 个云函数及其作用

| 序号 | 函数名 | 作用 |
| --- | --- | --- |
| 1 | `getUser` | 获取当前用户信息，首次使用自动创建 |
| 2 | `updateProgress` | 记录用户解锁或完成某个节点（作品/地图节点）的进度 |
| 3 | `grantBadge` | 为用户发放徽章（自动去重） |
| 4 | `getWorks` | 分页获取作品列表，支持按分类筛选 |
| 5 | `getWorkDetail` | 根据作品 ID 获取作品详情（含富文本与高清图片） |
| 6 | `getCloudMap` | 获取云图的所有节点与连接关系，用于知识图谱可视化 |
| 7 | `getDigitalHumanScript` | 根据场景获取数字人的台词脚本 |

---

## 二、6 个数据库集合及存储内容

| 集合名 | 存储内容 |
| :--- | :--- |
| **users** | 用户基本信息、进度记录、已获得徽章列表 |
| **badges** | 徽章字典（徽章 ID、名称、描述、图标、获取条件） |
| **works** | 作品基本信息、富文本内容、图片集、关联节点 |
| **cloud_nodes** | 云图节点信息（节点 ID、名称、类型、坐标、图标、关联作品） |
| **connections** | 云图节点间的连线关系（起点、终点、关系类型） |
| **digital_human_scripts** | 数字人各场景的台词文本、情绪、可选语音链接 |

> **批注:** 按功能分类，`users` + `badges` 属用户系统；`works` 属内容体系；`cloud_nodes` + `connections` 属知识图谱；`digital_human_scripts` 属数字人交互。

## 三、调用方式

### 3.1 请求方式

所有云函数均通过微信小程序端 `wx.cloud.callFunction` 调用：

```javascript
wx.cloud.callFunction({
  name: '函数名',
  data: { /* 参数 */ }
}).then(res => {
  console.log(res.result) // 返回结果
})
```

### 3.2 统一返回格式

所有云函数均使用 `utils/response.js` 封装，返回结构如下：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `code` | Number | 状态码，0 表示成功，非 0 表示错误 |
| `message` | String | 状态描述 |
| `data` | Object | 业务数据，具体结构见各接口 |

### 3.3 错误码约定

| code | 含义 |
| :--- | :--- |
| **0** | 成功 |
| **1001** | 参数缺失或格式错误 |
| **1002** | 用户不存在 |
| **1003** | 数据库操作失败 |
| **1004** | 徽章已存在（幂等） |
| **2001** | 作品不存在 |
| **2002** | 云图数据异常 |
| **2003** | 场景脚本未配置 |
| **9999** | 服务端未知错误 |

> W1 阶段暂不启用错误码校验，Mock 统一返回 `code: 0`。

**请求参数：**

| 参数 | 类型 | 必填 | 说明 |

| `action` | String | 是 | 操作类型，如 `"unlock"` |

  "message": "ok",

## 五、前端使用指南

1. 所有接口通过 `wx.cloud.callFunction` 调用，函数名即上述名称（小驼峰）。
2. 先按 `response.code == 0` 判断成功，再使用 `response.data`。
3. 分页列表注意处理 `hasMore` 为 `false` 时停止加载。
4. 上传各类 ID（如 `workId`、`nodeId`、`badgeId`）时按接口文档传递，无需额外编码。
5. Mock 数据中的 URL 和图片仅为示例，W2 接入真实数据后替换为云存储链接。
